# Screenshots

`home-screen.jpg` is the custom home window running in Kodi 21.3, captured by
`tools/check_windows.py`. It shows the hero, the trending anime row pulling
live artwork from AniList, and the Israeli live TV row.

Re-take it any time with:

    python tools/setup_kodi.py       once, to fetch a portable Kodi
    python tools/check_windows.py    opens the window and screenshots it
